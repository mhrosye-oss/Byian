# Firebase configuration templates

هذه المجلدات تحتوي قوالب فقط:

- `android/google-services.json.example`: مرجع لملف Android الذي يُنزّل من Firebase Console.
- `ios/GoogleService-Info.plist.example`: مرجع لملف iOS الذي يُنزّل من Firebase Console.

ضع الملفات الحقيقية في مساراتها المحلية المذكورة في [دليل إعداد Firebase](../docs/FIREBASE_SETUP.md). لا تضع service-account JSON أو مفاتيح FCM server داخل التطبيق.

العقود المطلوبة من backend موجودة في [CIRCLES_V2_BRIEF.md](../docs/CIRCLES_V2_BRIEF.md).
